## How to review (translation bounty)

1. Claim your language in the **#bounties** channel on Discord: https://discord.gg/V5PaU3SSY
2. Open your language file and compare each line with `site.en.json` (same keys).
3. Fix anything that sounds unnatural, wrong or too literal for native speakers. Keep HTML tags such as `<b>`, `<a href=...>` and `<code>` exactly as they are.
4. Send your reviewed file as a pull request to this repository, or attach it in #bounties.

Bounty rules and rewards are pinned in #bounties. One bounty per person.
